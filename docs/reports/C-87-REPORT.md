# گزارش فعالیت C-87 — ساخت نصب‌ساز حقيقي و راه‌اندازی اولیهٔ فروشگاه

## خلاصه

وظیفه C-87 ساخت یک فایل نصب‌ساز مستقل برای ویندوز و اضافه‌سازی صفحه راه‌اندازی اولیهٔ فروشگاه به برنامه کاندو بود. این نصب‌ساز از طریق گیت‌هاب قابل دانلود است و بعد از نصب دابل‌کلیک، در اولین اجرا، راه‌اندازی اولیهٔ فروشگاه از طریق رابط گرافیکی خود نرم‌افزار اجرا می‌شود، پایگاه داده و تنظیمات را پیکربندی می‌کند و نشست مالک را ایجاد می‌کند. بدون نیاز به پاور‌شل، ترمینال، ویرایش فایل یا ساخت دستی توکن.

فایل دانلودی: Kandoo-Setup-x64.exe

## تغییرات کد

src/Kandoo.Hub/Program.cs — لاگ کردن مالک راه‌اندازی در startup

src/Kandoo.App.Launcher/Program.cs — نقطه ورود launcher ویندوزی (WinForms)

src/Kandoo.App.Launcher/MainForm.cs — رابط گرافیکی راه‌اندازی اولیهٔ فروشگاه: ۳ مرحله (نام فروشگاه، پیکربندی خودکار، پایان)

src/Kandoo.App.Launcher/SharedTokenFile.cs — ذخیره توکن در فایل kandoo.device-token.v1.json

src/Kandoo.App.Launcher/LocalProfileStore.cs — ذخیره پروفایل کاربر در فایل JSON

src/Kandoo.App.Launcher/AppUserRole.cs — نوع‌های نقش کاربر (Store، Customer، Both)

packaging/HubPilot/KandooHub.Installer.iss — اسکریپت ایننو سِتاپ برای ساخت Kandoo-Setup-x64.exe

.github/workflows/ci.yml — ساخت launcher ویندوزی فقط روی windows-latest، ساخت نصب‌ساز، آپلود آرتیفاِت

RUN-LOCAL.md — بازنویسی برای نسخه نصب‌ساز
