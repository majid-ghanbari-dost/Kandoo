# C-23 — API-first operator surface

**Scope:** product catalog, native Sale draft/review/issue, optional print, SMS resend/status, and CI-generated OpenAPI. No UI and no frozen-contract edits.

## Delivered

- **Products:** authenticated list/search with bounded store/filter/kind-bound cursors; same-store/same-normalized-name cascade options; OCC edit for name/type/color/price/stock and ordered operator fields. `type` is the API projection of persisted `Product.Category`, with legacy `category` retained. Operator fields are ordered, bounded, unique-keyed, store-private, and included in restore only when present; empty legacy restore projections remain byte-compatible.
- **Tags and stock:** a supplied positive numeric tag is rejected on conflict and advances the watermark only when needed; an empty tag uses the next system value. Tags remain immutable and retired tags are not reused. Stock edits require `base_version` and append a non-zero `Adjustment`; stock is never rewritten as ledger state. Legacy create payloads omit the new properties and retain their pre-C-23 request hash.
- **Matching boundary:** the response names only the owner-approved match fields (`name`, `type`, `color`, `unit_price_rials`, `product_tag_number`, `stock_millis`). It performs no sibling-store read. Cascade options, including operator-defined values, come only from active same-name products in the authorized store.
- **Invoices:** API wrappers use the existing durable `invoice.draft_create`, `invoice.item_add`, and `invoice.issue` operations, preserving idempotency, locks, numbering, review fail-closed behavior, and replication. Sale is enabled; Rental and Other are listed but return HTTP 501 `SERVICE_TYPE_DISABLED` before creating an operation.
- **Print:** optional post-issue adapter call. The default result is `PRINT_ADAPTER_DISABLED`; `NOT_REQUESTED` covers omission. Print failure does not roll back or renumber an issued invoice.
- **SMS:** Cloud `SmsService.ResendAsync` requires a new operation ID, reuses only the original same-store/invoice phone and public link, and retains quota/rate/idempotency controls. `GetStatus` is store/invoice scoped and exposes no body, phone, or link. Hub resend/status routes use existing Hub sessions and an internal gateway; the default is fail-closed HTTP 503 `SMS_GATEWAY_NOT_CONFIGURED`. Tests use a deterministic no-network gateway. No live SMS, Cloud credential, or production transport is claimed.
- **OpenAPI:** Swashbuckle emits `/openapi/v1.json` from implemented Hub routes (no Swagger UI). Linux CI runs the generated-document contract test, validates all C-23 paths, writes the tested document, and uploads `kandoo-hub-openapi-c23`. Normative `docs/openapi.yaml` is unchanged.
