# C-58 — انتخاب و تغییر نقش با پروفایل محلی

## محدوده و تأییدهای صریح

- در اولین اجرا نقش‌های `فروشگاه نمونه`، `مشتری نمونه` و `فروشگاه و مشتری نمونه` ارائه می‌شوند و مقدار `store|customer|both` در MAUI Preferences محلی ذخیره و از «تنظیمات نقش» قابل تعویض است. **(د) همه هویت‌های نمایشی نقش با «نمونه» مشخص شده‌اند** و فهرست فاکتورها آغاز نشده است.
- **(الف) هیچ network call جدیدی به role flow اضافه نشده است.** انتخاب/تعویض نقش فقط پروفایل محلی و نمایش workspace را تغییر می‌دهد؛ customer-only نیز بارگذاری شبکه‌ای ندارد.
- **(ب) هیچ فایل token/auth یا design-token دومی ساخته نشده است؛** همان `Resources/DesignTokens.xaml` مشترک قبلی مصرف می‌شود و credential/session token جدیدی ذخیره نمی‌شود.
- **(ج) تفسیر Windows:** چون customer MVP فعلاً Android-only است، Windows فقط store ارائه می‌کند و customer/both مخفی است؛ customer/both ذخیره‌شده به store normalize و مقدار نامعتبر به first-run می‌رود. این تفسیر در H-06 نیز ثبت می‌شود.
- **(هـ) نام نمایشی «کندو» و package id `ir.kandoo.app` حفظ شده‌اند.** آیکون موقت hex-check با honey `#F2A900` روی ink `#2B1D0E`، adaptive foreground/background و monochrome layer موجود است؛ artwork رسمی برند نیست.
- Android theme استاندارد `Maui.SplashTheme` صریح است. smoke فقط dialog دقیق `System UI isn't responding` را با Wait dismiss می‌کند؛ app ANR، crash marker، XML نامعتبر پس از retry یا نبود role text همچنان fail است. evidence نشان داد row صفرِ `Auto` کل viewport را مصرف می‌کند؛ grid نقش اکنون row heightهای صریح دارد.
