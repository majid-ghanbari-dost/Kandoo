# C-58 — انتخاب و تغییر نقش با پروفایل محلی

## رفتار و تفسیر پلتفرم

- در اولین اجرا صفحه انتخاب نقش `فروشگاه نمونه`، `مشتری نمونه` یا `فروشگاه و مشتری نمونه` را نشان می‌دهد. فقط مقدار نقش (`store|customer|both`) در MAUI Preferences محلی ذخیره می‌شود و از «تنظیمات نقش» قابل تعویض است.
- **تفسیر Windows:** چون customer MVP فعلاً Android-only است، در Windows دکمه‌های customer و both مخفی می‌شوند و فقط store ارائه می‌شود؛ مقدار نامعتبر/ناسازگار ذخیره‌شده نیز به store normalize می‌شود.
- customer-only workspace فروشگاه را مخفی و فقط placeholder مشتری نمونه را نشان می‌دهد؛ both هر دو را نشان می‌دهد. **invoice-list UI آغاز نشده است.** نام‌های نمایشی همه دارای «نمونه» و banner داده نمایشی هستند.
- انتخاب/تعویض نقش هیچ Cloud یا Hub call ندارد. هیچ token یا credential ذخیره نشد و هیچ فایل design-token دومی ساخته نشد؛ همه صفحات همان `Resources/DesignTokens.xaml`، رنگ/فونت/spacing و touch targetهای قبلی را مصرف می‌کنند. دسترسی به صفحه کپی crash نیز حفظ شده است.
