# C-30 — UI technology comparison and throwaway spikes

**Scope:** comparison of MAUI, Avalonia, Flutter, and Hub-served local web/PWA; disposable MAUI/Avalonia spikes only. No real UI, product-technology final decision, device test, legal/tax claim, or local .NET/Python execution is claimed.

## Delivered evidence

- `docs/ui-technology-memo.md` compares Persian RTL, Windows/Android CI, generated Hub OpenAPI consumption, accessibility, and repository/team-skill evidence. Flutter and PWA are explicitly memo-only.
- `spikes/c30-maui/` and `spikes/c30-avalonia/` each contain one Persian RTL screen with accessibility labels and one real Hub probe. The screen and CI harness share probe source; CI starts the actual Hub and validates `/openapi/v1.json`.
- `.github/workflows/c30-spikes.yml` is path-scoped, uses `Invoke-CiStep.ps1`, builds Windows and Android for both candidates, and uploads machine-readable build/probe evidence. Spike projects are excluded from `Kandoo.sln`.
- Local review was static only: YAML parsing, diff/scope checks, RTL/probe marker inspection, and frozen-contract diff verification. CI is the executor.
