# C-43 — read-only Hub operational status

**Scope:** one authenticated Hub observation endpoint. No backup, replication, SMS send, gateway call, Faraz transport, credential, device/UI claim, or frozen-contract edit is introduced.

## Endpoint and projection

`GET /v1/stores/{store_id}/status/v0` uses the existing Hub bearer-session and store-isolation conventions. It emits `generated_at_utc` and `time_zone: UTC`; each observed timestamp is named `at_utc`. Every operational value has a sibling `reason`, which is JSON null for a known value. An unavailable value is JSON null with a stable reason rather than a fabricated zero or timestamp.

| Field | Source | Unknown reasons |
| --- | --- | --- |
| `version.value` | Hub assembly informational version, then assembly version | `VERSION_UNAVAILABLE` |
| `last_sync.at_utc` | Latest durable `replication_log.acknowledged_at` for the route store | `NO_ACKNOWLEDGED_SYNC` |
| `last_backup.at_utc` | UTC timestamp encoded by the existing `SqliteBackupService` filename in the configured backup directory | `BACKUP_DISABLED`, `NO_BACKUP_FOUND`, `BACKUP_STATUS_UNAVAILABLE` |
| `free_disk.bytes` | `DriveInfo.AvailableFreeSpace` on the Hub SQLite data-source drive | `DISK_SPACE_UNAVAILABLE` |
| `sms.enabled` | Existing `FarazSms:Enabled` configuration; absent retains its existing false default | `SMS_CONFIG_INVALID` |

The SMS object is explicitly `scope: CONFIGURATION_ONLY` and names its configuration key. It does not assert provider reachability or live delivery. Existing backup files remain observable when scheduling is disabled. The probe only reads: it does not create a backup directory, acknowledge an operation, or invoke replication.

## Tests and evidence boundary

`tests/Kandoo.Hub.Tests/HubStatusTests.cs` covers known values through the real route, real SQLite acknowledgement and real backup service, every null/reason projection, missing and cross-store authentication, disabled/missing/unavailable backup states, invalid/default SMS configuration, unavailable/available disk observations, and the absence of route-side replication effects. `OpenApiContractTests` requires the generated `/openapi/v1.json` path, requires GET, and rejects POST. Frozen `docs/openapi.yaml` is untouched.

Local .NET/PowerShell remain unavailable; local review is static only. Main CI is the compile/test/OpenAPI executor and must be observed green before publication.
