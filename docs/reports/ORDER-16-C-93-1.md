## جزئیات پیاده‌سازی

### HolooSchemaVersion

- کلاس sealed با سازنده خصوصی
- متد `Known(string? raw)`: اگر مقدار ورودی null، خالی یا فقط فاصله باشد، null برمی‌گرداند. اگر مقدار در لیست نسخه‌های معتبر (H1-6, H1-7, H1-8) باشد، یک نمونه برمی‌گرداند. در غیر این صورت null برمی‌گرداند.
- متد `TryParse(string?, out HolooSchemaVersion?)`: لایه لوتف برای Known.
- خصوصیت `Value`: مقدار رشته‌ای نسخه سما.
- هیچ رمز عبور ذخیره نمی‌شود، هیچ مقدار حدس زده نشده تولید نمی‌شود، فقط خواندنی است.

### تست‌ها

1. `SchemaVersion_known_trusted_versions_return_instance`: H1-6, H1-7, H1-8 باید نمونه معتبر برگردانند.
2. `SchemaVersion_unknown_or_empty_returns_null`: null، خالی، فاصله، H9-99، unknown باید null برگردانند.
3. `SchemaVersion_tryparse_matches_known`: TryParse باید با Known سازگار باشد.
