# C-45 — replication payload آزمایشی v1.1 با flag خاموش

## تحویل و تفسیر شکل داده

- تغییر فقط در Hub است. `PayloadV11Enabled` به‌صورت پیش‌فرض و بدون مقدار پیکربندی جایگزین **false** است. .NET Cloud، endpointهای Cloud و قراردادهای منجمد دست‌نخورده‌اند.
- برای حفظ hash و payload فعلی، v1.1 به‌جای بازنویسی `entries[].payload` سه افزوده batch-level دارد: `payload_version:"1.1"`، `currency` اختیاری و `invoice_payloads[]` اختیاری با `operation_id`. این شکل **تفسیر موقت** است تا رسیدن قرارداد PHP.
- `customer_name`، `payments[]` با `type` در چهار مقدار `card-reader|card-to-card|cash|credit` و `amount` صحیح، و `remaining_balance` فقط از داده ثبت‌شده `invoice.issue` خوانده می‌شوند. currency فقط از map صریح per-store با `rial|toman` خوانده می‌شود. هیچ total، balance، تبدیل ریال/تومان یا مقدار جایگزین محاسبه/ساخته نمی‌شود.
- API صدور فقط مقادیر اختیاری را در همان payload durable قبلی ثبت می‌کند؛ غایب‌ها omit می‌شوند و `currency` در payload فاکتور جعل نمی‌شود. اعتبار type/number و currency هنگام ON fail-closed است؛ OFF هیچ validation یا projection جدیدی اجرا نمی‌کند.
