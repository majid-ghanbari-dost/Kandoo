## Delivered

- `PublicInvoiceHtml` has one inline CSS custom-properties block and `var(--...)` rules using the shared honey/ink/cream/wax/green/review values, one spacing scale, and responsive/print rules.
- Vazirmatn Regular/Bold are bundled under `wwwroot/fonts`; `UseStaticFiles` serves only those local public assets. `OFL.txt` is bundled with them.
- The issuance label explicitly says Jalali and `Asia/Tehran`; conversion uses existing `JalaliDateConverter`, not a new calendar implementation. Integer amounts remain explicitly Rial.
- The HTML uses only the typed public projection. It visibly discloses that `customer_name` is absent and that a per-invoice `payment_method` field is absent at issuance; raw issued-payload values are not consulted or rendered. Existing legal-copy content remains HTML-encoded.
